## 功能说明与前置条件

验证搜索链接在首次打开和刷新时自动执行，手动编辑仍需提交。
使用独立 Vite 前端（`WEB_PORT=19876 BACKEND_PORT=19900 pnpm --dir web exec vite --host 127.0.0.1 --port 19876`），只读连接已有的测试抓包后端；不得清空流量、修改代理或重启正式服务。后端已有包含 `tab_v2` 的历史记录。
